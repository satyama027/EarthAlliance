End of Turn Report — design mockup. A blocking, dismissable modal shown right after End Turn, summarising how five planet metrics changed over the turn that just elapsed. Reuses the DataOverlay/EndingScreen overlay pattern (dark backdrop, centered window, framer-motion fade + rise; closes on Continue / ✕ / Esc / backdrop). Each row shows the new value + a colored Δ chip — the arrow shows direction, the color shows good/bad using the same vocabulary as the Turn Log (good = earth-3, bad = red, flat = dimmed). Up-is-bad: temperature, emissions, CO₂. Up-is-good: treasury, biodiversity.

Reopen button — in the header (📊, enabled once ≥1 turn has passed)
