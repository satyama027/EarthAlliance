Metric drill-down dashboard — “Full data” redesign (interactive mockup)

The 📊 Full data overlay becomes a 6-tile metrics grid that drills down. Two reusable renderers do all the work: Composition (contribution of each part — the stacked bar + clickable rows) and MetricTrend (a value-vs-year line graph). Where the engine models a real breakdown you drill into composition (Emissions → sectors → Electricity → coal/gas/oil; Income → parts); where it doesn’t, the node is a trend line. Click the tiles and rows below — it’s live. Toggle Planet ⇄ Region to see both entities.

How to read it
  • Level 0 — the 6 tiles: Emissions, Public support, Income, Biodiversity, Water availability, Land availability. Each shows the headline value + a mini trend.
  • Composition nodes (Emissions, Electricity, Income) show the stacked bar; each row is clickable — › drills further, 📈 opens that part’s trend line.
  • Trend leaves (the four index metrics, and every leaf sector/fuel) show the value-vs-year line — derived from turnLog snapshots, so history exists from turn 0 with no engine change.
  • Only Electricity has a real fuel split (coal/gas/oil, from the generation mix). Transport / industry / agriculture etc. go straight to a trend — no fabricated fuel numbers.
Breadcrumb navigates back at any depth. The same tree drives both the Planet and Region views — only the numbers differ.
