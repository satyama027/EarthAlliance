What changes vs. today

Layout: map cell uses height:100% with min-height:440px inside a stretched grid row, so it equals the info column — the blank band beneath the small map is gone, and the map is comfortably medium again. The image uses object-fit:contain so the entire world is always visible; the panel's ocean gradient fills the slim top/bottom bands.
Drag: the dragged card is rendered in a floating layer on top of the page (so it can never be clipped “under” a lane), the Active lane shows persistent empty slots as obvious drop targets, and a drop that lands on a slot stages the card there (it stays, outlined + “STAGED”). Click/keyboard still work as the accessible equivalents.
