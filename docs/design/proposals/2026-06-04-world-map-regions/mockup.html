World map — 10 regions on real geography

Flat, static world map (no rotation/zoom) built from real Natural Earth coastline data, not hand-drawn. The world's countries are grouped into the 10 regions; region boundaries (thick lines) fall on real national borders. Each region is clickable and is filled either by a distinct region color or by its publicSupport value (the in-game metric). This mockup loads map data + D3 from a CDN, so it needs internet; the real build bundles the data so the app is self-contained.
